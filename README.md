# Sistem Integrasi SATUSEHAT — Pendaftaran Pasien (FHIR R4)

Repositori ini berisi implementasi backend menggunakan **Laravel (PHP)** sebagai jembatan data antara fasilitas kesehatan dengan platform **SATUSEHAT** milik Kementerian Kesehatan RI, menggunakan standar internasional **FHIR R4** di environment Sandbox.
